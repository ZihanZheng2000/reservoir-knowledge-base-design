# Dataset Releases

This folder is for curated dataset releases assembled from validated workflow runs.

[`lake_powell_demo/`](lake_powell_demo/) is the featured demo dataset for the
NSF proposal: the validated Evidence Unit, Knowledge Card, Synthesis Card,
encoded index, and claim-evidence records from the July 29, 2026 Lake Powell
run (`runs/lake_powell_20260729_kb/`). See its own README for file-by-file
counts and provenance, and the main repository
[README](../README.md#what-this-demo-shows-the-lake-powell-case) for the
demo story.

A dataset release may include:

- source inventories;
- Evidence Unit, Knowledge Card, and Synthesis Card records;
- cross-document synthesis records;
- evidence-chain / claim-evidence maps;
- validation summaries;
- dataset documentation.

Do not place raw exploratory runs directly here. Promote only reviewed and documented outputs from `runs/`.
