# AGU26 Submission Draft — IN002

**Session:** IN002 — *Accelerating Scientific Discovery in Earth System Science
with Agentic AI*

This folder contains a methods-focused submission package for the current
reservoir-operation knowledge-base workflow.

- `submission_draft.md` contains the title, AGU abstract, optional
  plain-language summary, and a pre-submission evidence checklist.
- `figure_1_agentic_reservoir_kb.svg` is an editable three-panel overview
  figure.
- `figure_1_caption.md` contains the caption, alt text, panel rationale, and
  an image-generation prompt for an alternative polished rendering.

The draft is deliberately conservative: it describes implemented workflow
structures and artifacts, but does not claim retrieval accuracy, extraction
accuracy, or scientific findings that have not yet been evaluated on a
completed run.

AGU26 currently permits an English title of up to 300 characters, abstract
text of up to 2,000 characters excluding spaces, and one optional JPG or PNG
image. Confirm the current submission portal requirements immediately before
submission. [AGU abstract requirements](https://www.agu.org/Meetings/First-Timers-Guide/abstract-knowledge-center/Articles/Abstract-Requirements)
